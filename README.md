Application to automatically collect Total Battle game chests and insert them into a mysql/mariadb database
The graphical interface is available at https://github.com/crashbrtb/chestcounter

If you use a full HD monitor, you don't need to change the coordinates; just enter the information from the databases.

If your monitor uses a different resolution, change the coordinates to match your monitor's coordinates.

If your clan doesn't have a gym or university, just delete the session.

How to install: Download the files to the C:\chestcounter folder.
Run install.bat.
Run run.bat.

To set it to run automatically, configure the Windows Task Manager to run run.bat at regular intervals.
